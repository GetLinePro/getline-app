# GetLine VPN — Product Brief

## Goal

Выпустить официальный Android-клиент GetLine VPN на базе CMFA/Mihomo,
упростить первоначальное подключение и получить канал распространения
через Google Play, F-Droid и прямой APK.

## Target user flow

1. Пользователь устанавливает приложение.
2. Входит через существующий веб-кабинет либо импортирует subscription URL.
3. Приложение получает и обновляет подписку.
4. Пользователь выбирает рекомендуемый режим или конкретную группу.
5. Подключается одной кнопкой.

## MVP

- импорт существующей subscription URL;
- работа с текущей конфигурацией Remnawave;
- простой onboarding;
- рекомендуемая конфигурация по умолчанию;
- ручной выбор группы/узла;
- подключение и отключение;
- обновление подписки;
- переход в существующий личный кабинет;
- безопасная диагностика без утечки credentials.

## Not MVP

- iOS;
- нативная оплата;
- новый личный кабинет;
- push-уведомления;
- Telegram-авторизация;
- собственное VPN-ядро;
- скачивание исполняемого кода с сервера;
- полная переработка архитектуры CMFA.

## Success criteria

- текущая подписка работает без серверной миграции;
- первый запуск проще исходного CMFA;
- проект можно регулярно синхронизировать с upstream;
- приложение пригодно для Google Play;
- изменения не создают заметного роста обращений в поддержку.
